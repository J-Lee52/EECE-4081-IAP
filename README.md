# EECE 4081 IAP — Shot Timer

## Concept Brief

A mobile shot-timer application that uses a smartphone's microphone to detect firearm discharges and record the timing between shots, providing users with immediate feedback and a history of their training sessions and competition matches.

## Technology Stack

- **Language:** Kotlin
- **Platform:** Android
- **IDE:** Android Studio
- **Build System / Dependency Management:** Gradle
- **Testing:** JUnit / Android testing
- **Version Control:** Git
- **Repository:** GitHub
- **Development Device:** Android Emulator
- **AI Coding Tool:** GitHub Copilot & Claude
